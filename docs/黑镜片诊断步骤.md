# 黑镜片诊断 —— 操作步骤（给仓库主人）

> 目标：搞清楚"开光影时高倍镜是黑镜片"到底是**哪条路径**出的问题。
> 原因：代码里有两条互斥的路，病根和修法完全不同，但外观都是"黑镜片"：
>
> | 路径 | 开关 | 默认值 | 干什么 |
> |---|---|---|---|
> | **A. 目镜遮罩** | `ScopeMaskEnable` | **true（默认开）** | 让镜筒"透视"——把实心深色镜片材质在孔径内 discard 掉 |
> | **B. 画中画放大** | `ScopePipEnable` | false（默认关） | 透过镜片把世界再画一遍并放大 |
>
> 而且画中画在光影下还有第二道闸门 `ScopePipAllowShaderPacks`（**默认 false**），
> 没打开时画中画在光影下**完全不工作**。
>
> 所以：**如果你在默认配置下就看到黑镜片，那病在 A（默认配置就有病，比 README 写的严重得多）**；
> 如果你是开了画中画之后才看到的，那病在 B。**这两种情况必须分开对待。**

---

## 第 0 步：回答一个问题（最重要）

**你看到黑镜片的那次，游戏里是怎么设置的？** 只要回答这个：

- [ ] **我没动过任何设置，装上就开光影，高倍镜就是黑的** → 病在 A（严重）
- [ ] **我先进设置把"瞄具画中画"打开了，然后才黑的** → 病在 B（和 README 写的一致）
- [ ] **不记得了** → 那就按下面第 2 步的「两种都测一遍」做

---

## 第 1 步：打开诊断开关（改一个文件）

用记事本打开这个文件：

```
E:\GAME\MC\HMCL\.minecraft\config\tacz-client.toml
```

找到下面这几行，把值改成我写的这样（**只改 `=` 后面的部分**）：

```toml
ScopeMaskEnable = true          # 保持 true 不动
ScopePipDebugTrace = true       # 原来是 false → 改成 true（记录每一步决策）
ScopePipDebugPaintLens = true   # 原来是 false → 改成 true（把镜片涂成品红色）
```

> **`ScopePipDebugPaintLens` 是什么**：把"应该被放大的区域"涂成**品红色**。
> 这是最快分辨病因的办法——
> - 镜片变**品红** → 那条路径**跑到了**，只是画出来是黑的（问题在"画什么"）
> - 镜片还是**黑** → 那条路径**根本没走到**（问题在"闸门"）
>
> 别忘了测完把这两个开关改回 `false`，否则镜片一直是品红色。

---

## 第 2 步：两种都测一遍（各截一段日志）

**测试 A（默认配置，验病根是不是在遮罩）**

1. 把 `ScopePipEnable` 保持 **false**（默认）
2. 进游戏，启用光影包：**Complementary Reimagined r5.9.3**（或 Unbound，你两个都有）
3. 拿一把**4 倍以上**的枪（比如 AWP、高倍狙击），**开镜**，保持 3~5 秒
4. 记下你看到的：镜片是**黑**的，还是**品红**的，还是**正常透视**
5. **退出游戏**（这样日志才写完）

**测试 B（打开画中画 + 允许光影，验病根是不是在画中画）**

1. 把 `ScopePipEnable` 改成 **true**
2. 再把 `ScopePipAllowShaderPacks` 改成 **true**（否则光影下画中画不工作，测不出来）
3. 重复上面第 2~5 步（进游戏 → 开光影 → 高倍开镜 → 记录 → 退出）

> 每测完一轮，把日志**另存一份**再测下一轮，否则会被覆盖。

## 第 3 步：把日志给我（或者我自己读）

日志在：

```
E:\GAME\MC\HMCL\.minecraft\logs\latest.log
```

**你可以什么都不做**——告诉我"测完了"，我直接去读这个文件。
如果你想让我同时看到两轮，把第一轮的文件复制成 `latest-A.log` 放在同一个文件夹里。

我最关注的几行（你也可以自己搜来看）：

| 搜什么 | 说明什么 |
|---|---|
| `[TACZ Scope]` | 所有瞄具相关日志都带这个前缀 |
| `Iris scope-mask injection` | 遮罩注入到光影着色器有没有成功 |
| `scope pass` / `PIP COMPOSITE` | 画中画那一遍有没有真的跑 |
| `inactiveReason` / `a shader pack is active` | 被闸门挡住了（这会直接印出挡它的原因） |
| `Assigned custom scope pipelines to Iris HAND program` | 管线分配是否成功 |
| `Could not find a verifiable 'void main()'` | 光影的 HAND 着色器里没找到注入点（注入失败） |
